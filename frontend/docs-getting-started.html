Getting started

ROOT-A-TRON 3000 fits mathematical models to measured data using CERN's ROOT toolkit, the same fitting engine used in particle physics. A fit adjusts the parameters of a function until it best describes your measurements, and reports the fitted values with their uncertainties.

There are two workspaces for the same engine. Compact puts every control on one screen; Standard walks through the same steps - measurements, fit model, results - one at a time. A third page, Analyze Data, calculates further quantities from your data and fitted parameters with full uncertainty propagation. Switch between them from the links at the top of each workspace.

The usual workflow

  1. Choose an analysis type and enter your measurements - paste columns, or load an example. See Analysis types.
  2. Choose a fit function - write one, or pick from the model library.
  3. Enter starting guesses for the parameters and press Fit. See the Starting parameter guides.
  4. Read the results: fitted parameters, uncertainties, and goodness-of-fit.
