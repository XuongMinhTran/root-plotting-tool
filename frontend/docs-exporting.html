Exporting

Press Export to save your work. The options are:

  • PDF report - a formatted document with the plot, fitted parameters, goodness-of-fit, and any calculated values and notes.
  • LaTeX report - a .zip containing a LaTeX source file and the figures, ready to drop into a lab report.
  • Individual files - the plot as PNG and/or SVG, the data and results as CSV, and the session as JSON.
  • Complete session (JSON) - every dataset, calculation, and setting, which can be reloaded later to continue exactly where you left off.

Plots are exported exactly as drawn on screen - the PNG is rasterized at high resolution and the SVG is vector text from the live figure.
