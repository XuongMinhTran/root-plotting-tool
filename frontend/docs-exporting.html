Saving and exporting

Sessions

Save, on either page, downloads the whole session as one .json file: every dataset with its uncertainties, exclusions and reasons, its model and starting values, the last fit result with its drawn canvas, and every calculation with its bindings. Open… restores it, replacing the current session; on Analyze Data a session file can also be dropped onto the page. The stored canvas means a saved fit redraws immediately without the backend. The file is the record of the analysis, and the thing to keep.

From Make a Plot

Export PNG and Export SVG save the current plot as drawn, including any diagnostic panels. PNG is rasterised at high resolution for documents and slides; SVG is vector and editable, for figures that will be resized or restyled.

From Analyze Data

Export opens a dialog with three formats and a choice of content. Content is chosen by checkbox: graphs, calculated values and columns, fit parameters and diagnostics, raw data with exclusion reasons, the document notes, and the complete session. Which datasets and which calculations to include can be selected individually.

  • PDF report: a formatted document with the selected graphs, parameter tables, calculations and notes, generated in the browser.
  • LaTeX report: a .zip containing an editable report.tex, the tables as LaTeX, and the figures as PNG and SVG. Upload the whole ZIP to Overleaf as a new project, with report.tex as the main document and pdfLaTeX as the compiler; or compile locally. A compiled PDF is not included, so the text can be edited before it is typeset.
  • Individual files: CSV tables of data, results and calculations (values with their uncertainties), the plots as images, and optionally the session JSON, packaged as a ZIP when there is more than one.

Every export is produced locally in the browser; nothing is uploaded.
