Calculate quantity or column

Calculate from measurement columns or fitted parameters. Source uncertainties and fit covariance are propagated to the result.

Source quantities

Select a column or fitted parameter to insert it into the expression. Columns contain one value per row; fitted parameters are single values with uncertainties. Parameter [0], [1], etc. refer to the indices in the fit function.

Calculation

Type an expression, then assign its symbols to source values or columns. For example, t ln(2) or V/I. Type \tau for τ and \sqrt for a square root.

Typing reference

Type \alpha, \lambda, \sigma, \tau, or \pi followed by Space for Greek symbols. Use ^ for powers, _ for subscripts, / for fractions, and \sqrt for a square root. Use arrow keys to leave an exponent or fraction.

Functions require parentheses: exp(x), ln(x), sin(x). Adjacent symbols multiply. Assign each variable to a source quantity below; inserted quantities are assigned automatically. Example: t ln(2). Assign units to each input and select a result unit. Compatible units are converted automatically; enter 1 for dimensionless quantities.

Unit reference

Units are case-sensitive. Examples: mm, cm, nm, mm^-1, m/s^2, J/(mol*K), V/A, eV. Use *, /, parentheses, and numerical powers. Enter 1 for dimensionless quantities. Angles accept rad or deg. Celsius, Fahrenheit, and decibels are unsupported.

For a wavelength calculated as πd/(kD), assign d in mm, D in cm, k in mm^-1 if the fitted position was in mm, and the result in nm. Source unit assignments describe the existing numbers; they do not change the fitted data.

Symbol assignments

Inserted quantities are assigned automatically. For symbols you type, choose the corresponding source below.

Result preview

Uncertainty method

First-order propagation using numerical partial derivatives. Imported fit covariance and shared inputs are retained through subsequent calculations. Separate sources are assumed independent. Rows are paired by position; a scalar applies to every row. If an input uncertainty is unspecified, the result uncertainty is left unspecified.

Units and uncertainties are converted together, with dimensional consistency checked. Linear propagation may be inadequate near singularities or for large uncertainties and strongly nonlinear expressions.
