Data

Use original counts, before weighting, normalization or background subtraction.

Leave the bin count blank to use the range width, rounded up to a whole number (at least one bin). Without range limits, the smallest and largest measurements define the range.

Bin edges

Required for pre-binned counts: enter one more edge than counts. For measurements, custom edges replace the bin count and range above. Unequal widths are supported.

The plot shows counts per unit X, allowing bins of different widths to be compared. Values on the final right edge are included; measurements outside the edges are reported separately.

One value per line; commas, tabs or spaces work too. Errors are optional: enter one value for the whole axis, or one per point. Use Insert data… to type, paste or edit measurements in a table.

Fit function

The function describes counts per unit X. Its integral over each bin predicts that bin’s count. Poisson likelihood includes empty bins and is preferable for sparse counts. χ² excludes empty bins. The fit range selects bins by their centers.

Typing reference

Use x for the independent variable and [0], [1], … for fit parameters. Write multiplication as *, division as /, and powers as pow(x,2). Functions include exp(x), log(x), sin(x), and sqrt(x). Use TMath::Pi() for π. Example: [0]*exp(-x/[1])+[2].

x is the variable, parameters are [0], [1], … Named functions gaus, expo, landau, pol2 … also work. TFormula · TMath

Initial guesses matter for nonlinear fits. Estimate slopes, peak heights, positions, and widths from the data, using the model’s units. Poor guesses can prevent convergence or lead to a different minimum. Leave a value blank to use its default or automatic estimate, where available.

About ROOT-A-TRON 3000

Fits are computed server-side by CERN ROOT (Minuit) and drawn by JSROOT. Nothing you enter is stored on the server - use Save to keep your work.

Built by Minh Tran (2026) as a redesign of Dr. D. Beznosko's chi2 tool (Clayton State University), without accounts or server-side storage.
