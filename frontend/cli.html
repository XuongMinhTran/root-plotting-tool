Command Line Interface

Run ROOT/C++ commands in a persistent interpreter. Variables and objects remain available between commands, and canvases appear below. This workspace is independent of Classic and Modern.

ROOT console

Working with ROOT

Enter native ROOT/C++ statements, expressions, or complete multiline blocks. Include semicolons where C++ requires them. Commands run in order within this session. They can create ROOT objects, perform calculations, fit models, and draw 2D or 3D canvases. Use .help for ROOT’s interpreter commands.

A new session starts a fresh interpreter. Opened files and saved sessions restore text and canvas snapshots without executing code. To recreate objects, run their declarations again. A failed command may have executed some statements before the error; ROOT’s diagnostic output is retained below.

Objects declared inside a C++ block follow normal C++ scope rules. Use top-level declarations for variables you want to reference later. The local service has a 45-second limit per submission and ends sessions after one hour of inactivity. Session files preserve commands and canvas snapshots, not live C++ memory or files in the container.
