Fit functions & the model library

The fit function is written as a ROOT expression. Use x for the independent variable and [0], [1], … for the parameters to be fitted. Multiplication is *, division /, and powers pow(x,2) or x^2. Supported functions include exp, log, sqrt, sin, cos, and the TMath:: family; TMath::Pi() is π. ROOT also provides named functions such as gaus, expo, landau, and polynomials pol0…polN, which can be combined with parameter offsets, for example gaus(0)+pol1(3).

The Standard workspace additionally offers an equation editor: type an ordinary formula such as A exp(-x/tau) + B and it is translated to the ROOT expression for you, with the symbols becoming fit parameters.

The model library

Rather than remember the expression for every experiment, press Model library… next to the fit function. It opens a browsable, searchable collection of the models most common in undergraduate labs, grouped by topic - mechanics and motion, waves and optics, thermal and statistical, electricity and magnetism, modern physics, and general shapes.

Each entry shows the model, a one-line description of the experiment it fits, and the variables it expects. Choosing Use fills in the fit function, the parameter names, and starting guesses. Those guesses are a starting point, not an answer - adjust them to your own data before fitting.

For how to estimate the starting values for each model - whether or not you used the library - see the full Starting parameter guides.
