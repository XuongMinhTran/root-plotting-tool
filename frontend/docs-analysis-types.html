Data and analysis types

The data type decides how the measurements are stored, how they are weighted in the fit and what the model is a function of. Choose it from Data type before entering data; a dataset that already has data keeps its type, and choosing another type starts a new dataset.

One variable, y = f(x)

The common case: one measured quantity that depends on one controlled or measured quantity. The table has four columns, X, X uncertainty, Y and Y uncertainty. Each uncertainty column has a mode:

  • Per point: one value per row. Use it when the uncertainty varies, as for counts (σ = √N) or readings from different instrument ranges.
  • Constant: a single value applied to every row, typed in the header. Use it for a fixed instrument resolution, such as a ruler read to ±0.5 mm.
  • None: the quantity is treated as exact. For X this is often right (a set voltage, a chosen length). For Y it means the fit is unweighted: every point counts equally, χ² is computed as if each point had σ = 1 and so is in arbitrary units, χ²/NDF and the p-value lose their meaning, and the parameter uncertainties assume that same σ = 1 and should not be quoted. Prefer a real estimate, even a rough one.

How X uncertainties enter the fit is described under effective variance.

Entering data

Type into the cells, or paste a block copied from a spreadsheet; it fills rightwards and downwards from the cell you paste into, in the order the columns are shown. If the first pasted row is a header, the columns are matched by name: x, y, and for uncertainties any of u(y), dy, σy, y uncertainty, y error and similar. A pasted column that lands on a Constant or None uncertainty switches it to Per point. Import CSV does the same from a .csv, .tsv or .txt file. Columns can be dragged into any order by the grip at the left of their header; the order is only for display and is remembered per data type.

The preview beside the table redraws as you type, so a swapped column or a misplaced decimal point shows up before you fit. The status line under the table reports the point count and the uncertainty modes, and names anything that stops the dataset from being fitted (a missing value, a negative uncertainty, a gap in a per-point column).

Several datasets

A worksheet can hold any number of datasets, each with its own type, model and result; + New dataset adds one and the tabs switch between them. Options renames, duplicates or deletes the current dataset and resets its column order. Plot titles and axis labels belong to the worksheet as a whole. Each dataset is fitted separately.

Histogram

A distribution of one measured quantity, fitted bin by bin. Supply either:

  • Individual measurements, which the tool bins. By default the bins are one unit of x wide across the range of the data (⌈max − min⌉ bins, the last edge inclusive), which suits integer-valued data such as channel numbers; for anything else set a bin count and range, or give explicit bin edges.
  • Bin counts that are already histogrammed, as (lower edge, upper edge, count) rows; the bins must touch.

The model is a density: the fit integrates it over each bin (ROOT fit option I with WIDTH) and compares the integral with the count, so a bin twice as wide is expected to hold twice the count and unequal bins are handled correctly. Named functions such as gausn are normalised, so their first parameter is the total area, not the peak height.

Two fit methods:

  • Poisson likelihood (default; ROOT option L). Each count is treated as a Poisson variable with the model's integral as its mean. This is exact for counting data and correct at low counts, where √N is a poor uncertainty; empty bins carry information and are included. The report gives the Poisson deviance in place of χ². It behaves like χ² for large counts, but a p-value is not reported because the χ² approximation is unreliable.
  • χ² with √count uncertainties. Each bin gets σ = √N; empty bins have no defined uncertainty and are omitted. Fine when every bin holds tens of counts or more; biased low otherwise, because downward fluctuations get smaller uncertainties and more weight.

Multivariate, Rn → Rm

A model with several inputs, several outputs, or both: intensity as a function of two positions, or two quantities measured together that share parameters. Choose the number of inputs n and outputs m, enter one column per input and per output, each with an optional uncertainty column, and write one model per output. Models use x0, x1, … for the inputs and [0], [1], … for the parameters; parameters are shared by index, so [2] in two output models is one parameter fitted to both.

The fit minimises one global χ² over every output and point, with input uncertainties folded in by the same effective-variance rule as the XY fit, using numerical derivatives of each model with respect to each input. Minuit does the minimisation, so the report has the same form: parameters with uncertainties from the covariance matrix, χ², NDF and the status. With one input the result is drawn as a curve, with two as a fitted surface, and with more as a slice along the first input with the others held at their means. Residual and pull diagnostics are available in any dimension. The Beam profile example is a 2-D Gaussian on a 7×7 grid.
