Analysis types

Choose the type that matches your measurement before entering data.

XY data

One input and one measured output - the common case. Enter X and Y columns, with optional uncertainties on either axis. Uncertainties may be a single value for the whole column or one value per point. When X uncertainties are given, the fit combines them with the Y uncertainties by the effective-variance method (see Uncertainties).

Histogram

A distribution of a single measured quantity. Enter individual measurements to be binned, or existing bin edges and counts. Histograms can be fitted with a Poisson likelihood (recommended for low counts; it includes empty bins) or with a χ² using √count uncertainties (which excludes empty bins).

Multivariate (Rn → Rm)

A model whose inputs and outputs can each have several dimensions - a quantity that depends on two or three variables, or several outputs measured together. Choose the number of inputs n and outputs m, then enter one column per input and per output (each with optional uncertainties) and one model per output. Write models with inputs x0, x1, … and parameters [0], [1], …; a parameter that appears in more than one output is shared across them. With one input and one output the fit draws the curve; with two inputs it draws the fitted surface; with more, it shows a slice along the first input with the others held at their mean. Residual and pull diagnostics work in any dimension. Load the Beam profile example to see a worked R²→R fit.
