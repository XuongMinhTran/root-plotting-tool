Fit model

The model is a count density; its bin integral gives the expected count. Poisson likelihood includes empty bins; χ² uses √count uncertainties and excludes empty bins. Fit-range limits select bins by their centers.

Typing reference
            
Equation editor: type sqrt for a square root, / for a fraction, ^ for a power, and _ for a subscript. Use Ctrl/⌘ + Z to undo. Use the arrow keys to move out of a fraction, exponent, or subscript. You can also paste LaTeX.

            
For Greek letters, type alpha, beta, mu, sigma, tau, lambda, or theta. Use pi for π. Other Greek letters can be entered as LaTeX commands such as \omega, followed by Space. e and π are constants.

            
Adjacent symbols multiply: ab means a × b. For a parameter with a longer name, use \mathrm{background}. A subscripted symbol such as x_0 is a parameter. Report names can differ from equation symbols.

            
Functions need parentheses: exp, ln, log, log10, sin, cos, tan, asin, acos, atan, sinh, cosh, tanh, sqrt, abs, erf, erfc, pow, min, max, atan2, and sinc. sinc(z) means sin(z)/z, with value 1 at zero. Example: A exp(-x/tau) + B.

            
ROOT expression: write multiplication as *, division as /, and powers as pow(x,2) or x^2. Parameters are numbered from zero. Named functions such as gaus, gausn, expo, landau, and pol2 are supported. Example: [0]*exp(-x/[1])+[2].
