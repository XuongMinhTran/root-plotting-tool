Measurements

Enter unweighted, nonnegative integer counts before normalization or background subtraction.

Leave the bin count blank to use the range width, rounded up to a whole number (at least one bin). If both range limits are blank, the sample minimum and maximum define the range.

Bin edges

For N bins, enter N + 1 strictly increasing edges. Explicit edges override the bin count and range.

The plot shows counts per unit X, so bins of different widths can be compared. Values on the final right edge are included; measurements outside the edges are reported separately.

Fit model

The model is a count density; its bin integral gives the expected count. Poisson likelihood includes empty bins; χ² uses √count uncertainties and excludes empty bins. Fit-range limits select bins by their centers.

Function input

x is the independent variable. Other symbols become fit parameters; e and π are constants. Type x_0 for a subscript or x^2 for a power.

Typing reference

Use x for the independent variable and [0], [1], … for fit parameters. Write multiplication as *, division as /, and powers as pow(x,2). Functions include exp(x), log(x), sin(x), and sqrt(x). Use TMath::Pi() for π. Example: [0]*exp(-x/[1])+[2].

Use x for the independent variable and [0], [1], … for parameters. ROOT named functions and TMath expressions are supported.

ROOT expression
Typing reference

Type alpha, beta, mu, sigma, tau, lambda, or theta for Greek symbols, and pi for π. Other Greek letters can be entered as LaTeX commands, such as \omega, followed by Space. Type sqrt for a square root, / for a fraction, ^ for a power, and _ for a subscript. Use Ctrl/⌘ + Z to undo.

Enter the right-hand side of the model, for example A exp(-x/tau) + B. Use the arrow keys to move out of a fraction, exponent, or subscript. LaTeX expressions can also be pasted into the field.

Adjacent symbols multiply: ab means a × b. For a single parameter with a longer name, enter \mathrm{background}. A subscripted symbol such as x_0 is a parameter. Report names can differ from equation symbols.

Functions require parentheses. Supported functions include exp, ln (natural logarithm), log (natural logarithm), log10, sin, cos, tan, asin, acos, atan, sinh, cosh, tanh, sqrt, abs, erf, erfc, pow, min, max, and atan2. Use ROOT expression mode for other ROOT functions.

TFormula syntax · TMath functions - named functions such as gaus, expo and pol2 are supported.

Parameters

Initial guesses matter for nonlinear fits. Estimate slopes, peak heights, positions, and widths from the data, using the model’s units. Poor guesses can prevent convergence or lead to a different minimum. Leave a value blank to use its default or automatic estimate, where available.
