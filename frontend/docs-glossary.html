Glossary

Parameter
A number the fit adjusts to describe the data, written [0], [1], … in a ROOT expression.
Initial guess
The starting value for a parameter, from which the fit's search begins. Not an uncertainty and not a fixed value.
χ² (chi-square)
The total squared mismatch between data and model, measured in units of the data uncertainties.
NDF
Number of degrees of freedom: fitted points minus free parameters.
χ²/NDF (reduced χ²)
χ² per degree of freedom; near 1 when the model fits within the stated uncertainties.
p-value
The probability of a χ² at least this large if the model were correct.
Residual
Data minus fit at a point.
Pull
A residual divided by its uncertainty; the pulls of a good fit scatter like a standard normal.
Covariance / correlation
How the uncertainties of fitted parameters are linked; strong correlation means the data do not separate those parameters well.
Confidence band
The uncertainty in the fitted curve itself, from the parameter covariance - not a prediction interval for new data.
Effective variance
The method that folds X uncertainties into the fit alongside the Y uncertainties.
