Fit function

A ROOT TFormula: x is the variable, parameters are [0], [1], … Named functions gaus, expo, landau, pol1, pol2 … also work. Functions: exp log log10 sqrt pow abs sin cos tan asin acos atan sinh cosh tanh and TMath:: (e.g. TMath::Exp, TMath::Pi()). See also TF1.

Without guesses every parameter starts at 0. That is fine for straight lines and polynomials, and ROOT finds its own starting values for a lone gaus, expo or landau — but for anything else (sums like gaus(0)+pol0(3), exponentials, sines) read rough values off your data and type them here.

About ROOT Fit

Fits are computed server-side by CERN ROOT (Minuit) and drawn by JSROOT. Nothing you enter is stored on the server — use Save document to keep your work.

A redesign of Dr. D. Beznosko's chi2 tool (Clayton State University), without accounts or server-side storage.
