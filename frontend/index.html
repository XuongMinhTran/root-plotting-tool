Choose an interface

Choose the arrangement you find more comfortable for entering data and reviewing a fit. You can use the form controls in Classic or Modern, or use native ROOT/C++ in the independent Command Line Interface.

Classic

The Classic interface keeps controls close together in a compact layout modeled on desktop analysis software. This arrangement may be convenient when you are making frequent adjustments and prefer to see more controls at once.

Open Classic UI

Modern

The Modern interface uses a wide form with separate sections for data, fit settings, and results. You can move between these sections without scrolling through the whole analysis, while keeping room around the fields you are working with.

Open Modern UI

Command Line Interface

Run native ROOT/C++ commands in an independent session for calculations, ROOT objects, macros, and 2D or 3D canvases. Use it for work beyond the form controls, with variables and objects available between commands.

Open Command Line Interface

Classic and Modern share your current analysis within this browser. The Command Line Interface keeps its own session and saved files.

What is ROOT?

A framework for understanding scientific data, developed at CERN.

ROOT provides tools to process data, perform statistical analysis, and create scientific graphics. Researchers use it to explore measurements and test models.

How this plotting tool uses ROOT
ROOT fits your function to your measurements and calculates parameter uncertainties. JSROOT brings the resulting plot into your browser.

You can work with those tools here by entering data and choosing a function.
