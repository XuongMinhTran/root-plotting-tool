ROOT Fit

Non-linear curve fitting with CERN ROOT: parameters with uncertainties, χ²/NDF, p-value, and a proper plot.

Settings

Where the ROOT server runs. http://localhost:8000 is the Docker container on this machine.

Document

Data

One value per line — commas, tabs or spaces are fine too. Error columns are optional; leave them empty for an unweighted fit.

Fit function

A ROOT TFormula: x is the variable, parameters are [0], [1], … Named functions gaus, expo, landau, pol1, pol2 … also work. Functions: exp log log10 sqrt pow abs sin cos tan asin acos atan sinh cosh tanh and TMath:: (e.g. TMath::Exp, TMath::Pi()). See also TF1.
