Choosing initial fit parameters

A fit adjusts the parameters of a function to describe your measurements. Initial guesses are the values from which that adjustment starts. They are not measurement uncertainties, and entering a guess does not fix a parameter at that value.

For nonlinear functions, such as decays and oscillations, the starting values can determine whether the fit converges and which solution it reaches. Estimates from the measured shape are usually more useful than assigning every parameter the same value.

Parameter order and units

In a ROOT expression, [0], [1], and so on identify parameters. Their meanings follow from the expression, not their display names. For example, in [0]*x+[1], [0] is the slope and [1] is the intercept. Renaming them does not change the equation.

Enter guesses in this order in the parameter table or comma-separated field. In Standard, expand Paste comma-separated parameters to enter a list. Parameter settings belong to the selected dataset.

Use values consistent with the numerical units of your X and Y data. If X is time in seconds and Y is voltage in volts, a slope has units of V/s and an intercept has units of V. Graph labels do not convert the numbers used in a fit. A width or decay time appearing in a denominator needs a nonzero starting value.

Estimating starting values

First identify the approximate background, positions of important features, and the scale over which the signal changes. Use the part of the data you intend to fit. The examples below use ROOT expression syntax; the parameter meanings also apply when entering the same model in the equation editor.

Straight line
[0]*x+[1]

Estimate the slope from two well-separated representative points: m ≈ (y₂ − y₁)/(x₂ − x₁). Then estimate the intercept with b ≈ y₁ − mx₁. Points near (1 s, 3 V) and (5 s, 11 V) give 2, 1: a slope of 2 V/s and an intercept of 1 V. Exact starting values are generally less important for a line than for a nonlinear model.

Exponential decay with background
[0]*exp(-x/[1])+[2]

The parameters are amplitude at x = 0 above background, decay time constant, and constant background. Estimate the background from a region where the decay is nearly complete. Subtract it before estimating the amplitude or time constant.

Suppose the signal is about 105 at x = 0 and approaches 5 at late times. Start with amplitude 100 and background 5. If the signal reaches about 42 at x = 2 s, its excess above background has fallen to approximately 100/e ≈ 37, giving a time constant near 2 s. Enter 100, 2, 5.

If you can estimate the half-life instead, divide it by ln(2) ≈ 0.693 to obtain the time constant. ROOT’s named function expo uses a different convention, exp([0] + [1]x); its parameters are not amplitude and time constant.

Gaussian peak with background
[0]*exp(-0.5*((x-[1])/[2])^2)+[3]

The parameters are peak height above background, peak center, standard deviation σ, and background. Estimate the width at half the peak’s height above background, then divide that full width by approximately 2.355 to estimate σ.

For a peak at x = 10 with maximum Y = 135, background 15, and full width at half height 3.53, enter 120, 10, 1.5, 15. The center and σ have the same units as X; the height and background have the same units as Y.

For histograms, this tool displays counts divided by bin width. Estimate peak height from that density, not directly from a bin’s count. The named function gaus uses peak height, while gausn uses total area as its first parameter. For an isolated Gaussian fully covered by the measured range, the total number of entries provides an approximate area estimate.

Periodic patterns

Read the frequency convention directly from the expression. In [0]*sin([1]*x+[2])+[3], estimate [1] as 2π divided by the period in X. When X is time, this parameter is angular frequency. The amplitude is approximately half the peak-to-trough difference, and the offset is their midpoint. Choose the phase to match where the cycle begins.

For a squared-cosine model [0]*pow(cos([1]*(x-[2])),2)+[3], such as the interference factor in a double-slit pattern, neighboring maxima are instead separated by π/k, where k is [1]. A fringe spacing of 0.74 mm suggests k ≈ 4.25 mm−1. Confusing these two conventions gives a frequency estimate that differs by a factor of two.

Leaving guesses blank

A blank entry leaves that parameter unspecified. The fit uses a default or an automatic estimate where available. Blank does not mean “try all possible values.” In a comma-separated list, 100,,5 supplies values for [0] and [2], while leaving [1] unspecified.

ROOT can initialize some named functions automatically. This tool also estimates starting values for supported histogram models. Custom expressions and combinations of functions may require explicit guesses. For XY fits, ROOT’s automatic initialization of named functions can replace supplied guesses; use an explicit expression such as the Gaussian above when you need control of those starting values. See the ROOT fitting manual for its initialization conventions.

Checking the fit

After fitting, check the convergence status, fitted curve, parameter uncertainties, and residuals. Convergence means the fitting procedure met its stopping conditions; it does not establish that the model describes the experiment adequately.

If a nonlinear fit fails or gives implausible values, check the parameter order, signs, units, and function definition first. Then try other physically reasonable starting values. If substantially different guesses lead to the same fitted curve and parameters, that supports the numerical stability of the result. If they lead to different solutions, compare the fit statistic and residuals, and consider whether the measured range can distinguish those solutions.

Large uncertainties or strong parameter correlations can indicate that the data do not determine the parameters separately. Changing starting values cannot supply information missing from the measurements. Do not adjust measurement uncertainties simply to make a fit appear acceptable.
